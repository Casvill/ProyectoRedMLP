## Clasificación de Imágenes – Redes Neuronales Convolucionales

Este repositorio contiene dos versiones del proyecto, cada una trabajando con un conjunto de datos diferente. Cada versión se encuentra en su propia rama:
   
Ramas del Proyecto   
1. fashion-mnist

En esta rama se encuentra la implementación del proyecto utilizando el conjunto de datos Fashion-MNIST, un dataset de imágenes de prendas de vestir ampliamente usado como alternativa a MNIST para tareas de clasificación.  

2. persian-characters

Esta rama contiene la versión del proyecto que trabaja con el conjunto de datos
Persian Characters and Digits, disponible en Kaggle:   

https://www.kaggle.com/datasets/sadrabroo/persian-characters-and-digits    
   
Incluye el preprocesamiento, entrenamiento y evaluación del modelo aplicado a caracteres y dígitos persas.
